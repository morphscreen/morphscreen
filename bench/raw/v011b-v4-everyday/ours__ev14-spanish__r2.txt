## 1. Greetings & Politeness

<Flashcards title="Greetings">
| Front | Back |
|---|---|
| Hola | Hello |
| Buenos días | Good morning |
| Buenas tardes | Good afternoon |
| Buenas noches | Good evening / Good night |
| Por favor | Please |
| Gracias | Thank you |
| De nada | You're welcome |
| Perdón | Excuse me (to get attention or apologize) |
| Lo siento | I'm sorry |
| Sí / No | Yes / No |
</Flashcards>

<Callout tone="info" title="Pronunciation tip">
**Hola** is pronounced *OH-lah* (the H is silent). **Gracias** is *GRAH-see-ahs*. Roll the R lightly!
</Callout>

## 2. Getting Around

<Flashcards title="Travel phrases">
| Front | Back |
|---|---|
| ¿Dónde está…? | Where is…? |
| el baño | the bathroom |
| la estación de tren | the train station |
| el aeropuerto | the airport |
| el hotel | the hotel |
| la playa | the beach |
| ¿Cuánto cuesta? | How much does it cost? |
| un billete | a ticket |
| la cuenta | the bill / check |
</Flashcards>

<Callout tone="success" title="Key phrase pattern">
Just add a place after **¿Dónde está…?** — for example: *¿Dónde está el baño?* (Where is the bathroom?)
</Callout>

## 3. Ordering & Shopping

<Flashcards title="Restaurant & Shop">
| Front | Back |
|---|---|
| La cuenta, por favor | The check, please |
| Quisiera… | I would like… |
| un café | a coffee |
| un agua | a water |
| una cerveza | a beer |
| la comida | the food |
| ¿Tiene…? | Do you have…? |
| el menú | the menu |
| ¿Aceptan tarjetas? | Do you accept cards? |
</Flashcards>

<Callout tone="warning" title="Watch out!">
In Spain, **cerveza** is *ther-BEH-thah* (lisp the C). In Latin America it's *ser-BEH-sah*. Both are correct!
</Callout>
