# Speeding up a 2 GB CSV read in Python

Reading a 2 GB CSV is slow because Python loads everything into memory and parses every row one by one. Here's a structured approach to make it faster.

<Card title="Quick wins — try first">
<Columns>
<Stat label="Memory use" value="2 GB+" tone="warning" icon="chart-line" />
<Stat label="Typical speedup" value="5-10×" tone="success" icon="chart-line" />
</Columns>

1. **Use `pandas` with the right engine** — `pandas.read_csv('file.csv', engine='c')` is 10× faster than pure Python `csv.reader`.
2. **Only read the columns you need** — add `usecols=['col_a', 'col_b']`.
3. **Set data types** — `dtype={'col': 'int32'}` reduces memory and parsing.
4. **Read in chunks** — `chunksize=100_000` processes rows in batches instead of all at once.

<Button ask="Show me a code example with pandas">Pandas example</Button>
</Card>

<Card title="Chunked processing pattern">
<Code file="chunked_read.py" highlight="1,5,7">
import pandas as pd

chunks = pd.read_csv(
    'large_file.csv',
    usecols=['id', 'timestamp', 'value'],
    dtype={'id': 'int32', 'value': 'float32'},
    chunksize=100_000
)

results = []
for chunk in chunks:
    # Process each chunk
    chunk['value'] = chunk['value'] * 2
    results.append(chunk)

final = pd.concat(results)
</Code>

<Tab title="DuckDB">
<Code file="duckdb_query.py">
import duckdb

# Queries the CSV directly, no full load
result = duckdb.sql("""
    SELECT id, SUM(value)
    FROM 'large_file.csv'
    WHERE date > '2025-01-01'
    GROUP BY id
""").fetchdf()
</Code>
<Badge tone="success">10-50× faster</Badge>
</Tab>
<Tab title="Polars">
<Code file="polars_lazy.py">
import polars as pl

# Lazy evaluation — only processes what you need
df = pl.scan_csv(
    'large_file.csv',
    low_memory=True
).filter(
    pl.col('date') > '2025-01-01'
).group_by('id').agg(
    pl.col('value').sum()
).collect()
</Code>
<Badge tone="success">5-20× faster</Badge>
</Tab>
<Tab title="Dask">
<Code file="dask_parallel.py">
import dask.dataframe as dd

# Parallel execution across CPU cores
df = dd.read_csv('large_file.csv')
result = df.groupby('id').value.sum().compute()
</Code>
<Badge tone="info">Parallel, good for clusters</Badge>

<Card title="Convert to Parquet — one-time speedup">
Converting to Parquet makes future reads **10-100× faster** and uses **50-80% less disk space**.

<Code file="csv_to_parquet.py">
import pandas as pd

# Read in chunks to save memory
chunks = pd.read_csv('large_file.csv', chunksize=500_000)
for i, chunk in enumerate(chunks):
    mode = 'w' if i == 0 else 'a'
    chunk.to_parquet('large_file.parquet', engine='pyarrow', mode=mode)
</Code>

Then read instantly:
```python
df = pd.read_parquet('large_file.parquet')
```
