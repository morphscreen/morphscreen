## Slides' Main Points

<Card title="Slides: Key Takeaways" subtitle="12 slides • Core concepts covered" icon="presentation">
### Slide 1: What is Machine Learning?
- Definition: Algorithms that improve automatically through experience
- Distinction from traditional programming: learn patterns from data instead of explicit rules

### Slide 2: Types of Learning
- **Supervised**: Labeled data (classification, regression)
- **Unsupervised**: Unlabeled data (clustering, dimensionality reduction)
- **Reinforcement**: Learning from rewards/penalties

### Slide 3: The ML Pipeline
1. Data collection → 2. Preprocessing → 3. Feature engineering → 4. Model selection → 5. Training → 6. Evaluation → 7. Deployment

### Slide 4: Bias-Variance Tradeoff
- High bias = underfitting (model too simple)
- High variance = overfitting (model too complex)
- Goal: find the sweet spot

### Slide 5: Evaluation Metrics
- Classification: Accuracy, Precision, Recall, F1-score, ROC-AUC
- Regression: MSE, RMSE, MAE, R²

### Slide 6: Cross-Validation
- k-fold CV for robust performance estimates
- Prevents overfitting to a single train/test split

### Slide 7: Feature Scaling
- Standardization (z-score) vs Normalization (min-max)
- Critical for distance-based algorithms (KNN, SVM, neural nets)

### Slide 8: Regularization
- L1 (Lasso): sparsity, feature selection
- L2 (Ridge): weight decay, prevents large coefficients

### Slide 9: Ensemble Methods
- Bagging (Random Forest): reduce variance
- Boosting (XGBoost, LightGBM): reduce bias
- Stacking: combine diverse models

### Slide 10: Common Pitfalls
- Data leakage • Imbalanced classes • Overfitting to test set • Ignoring domain knowledge

### Slide 11: Production Considerations
- Model monitoring • Drift detection • A/B testing • Retraining pipelines

### Slide 12: Next Steps
- Deep learning fundamentals • NLP & Computer Vision • MLOps practices
