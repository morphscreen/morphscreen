### Key Concepts

**Compound Components** allow you to create components that work together as a cohesive unit, while giving the consumer control over composition and layout.

```jsx
// Parent manages state, children render UI
<Select>
  <Select.Trigger>Choose...</Select.Trigger>
  <Select.Options>
    <Select.Option value="a">Option A</Option>
    <Select.Option value="b">Option B</Option>
  </Select.Options>
</Select>
```

### Benefits
- **Separation of concerns** — logic in parent, rendering in children
- **Flexible composition** — consumer controls markup order
- **Implicit state sharing** — no prop drilling needed
- **Type-safe APIs** — TypeScript can infer relationships

### When to Use
- Tabs, Selects, Menus, Accordions
- Form field groups with validation
- Complex UI widgets with multiple interactive parts

### Implementation Pattern
1. Create context in parent component
2. Expose child components as static properties
3. Children consume context via `useContext`
4. Render props or `children` for maximum flexibility

### Common Pitfalls
- Forgetting to provide default context values
- Not handling missing context gracefully
- Over-engineering simple components
