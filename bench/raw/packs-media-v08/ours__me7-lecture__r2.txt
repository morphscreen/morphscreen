## Slides' Main Points

<Card title="Key Concepts Covered" icon="chart-line">
<Details title="1. Problem Setup & Notation" open="true">
- Supervised learning: learning a function f: X → Y from labeled examples
- Training set: {(x⁽¹⁾, y⁽¹⁾), ..., (x⁽ᵐ⁾, y⁽ᵐ⁾)} where x ∈ ℝⁿ, y ∈ ℝ (regression) or y ∈ {0,1} (classification)
- Hypothesis space ℋ: set of candidate functions we consider
</Details>

<Details title="2. Linear Regression">
- Hypothesis: h_θ(x) = θ₀ + θ₁x₁ + ... + θₙxₙ = θᵀx
- Cost function: J(θ) = ½m Σ(h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²
- Gradient descent update: θ_j := θ_j - α ∂/∂θ_j J(θ)
- Normal equation: θ = (XᵀX)⁻¹Xᵀy (closed-form solution)
</Details>

<Details title="3. Logistic Regression">
- Hypothesis: h_θ(x) = g(θᵀx) where g(z) = 1/(1+e⁻ᶻ) (sigmoid)
- Decision boundary: θᵀx = 0
- Cost function: J(θ) = -1/m Σ[y⁽ⁱ⁾log(h_θ(x⁽ⁱ⁾)) + (1-y⁽ⁱ⁾)log(1-h_θ(x⁽ⁱ⁾))]
- Regularization: add λ/2m Σθⱼ² to prevent overfitting
</Details>

<Details title="4. Model Evaluation">
- Train/validation/test split (e.g., 70/15/15)
- Regression metrics: MSE, RMSE, MAE, R²
- Classification metrics: accuracy, precision, recall, F1, AUC-ROC
- Cross-validation: k-fold CV for robust estimates
- Bias-variance tradeoff: underfitting vs. overfitting
</Details>

<Details title="5. Practical Considerations">
- Feature scaling: standardization vs. normalization
- Feature engineering: polynomial features, interaction terms
- Handling missing data: imputation strategies
- Regularization: L1 (Lasso) vs L2 (Ridge) vs Elastic Net
</Details>
</Card>
