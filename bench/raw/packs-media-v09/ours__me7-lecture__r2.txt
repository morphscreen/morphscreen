<Tab title="Linear Regression">
### Core Concepts
- **Supervised learning**: Learn mapping $f: X \to Y$ from labeled examples $(x^{(i)}, y^{(i)})$
- **Linear hypothesis**: $h_\theta(x) = \theta_0 + \theta_1 x_1 + \dots + \theta_n x_n = \theta^T x$
- **Cost function (MSE)**: $J(\theta) = \frac{1}{2m} \sum_{i=1}^m (h_\theta(x^{(i)}) - y^{(i)})^2$

### Key Assumptions
| Assumption | What It Means |
|---|---|
| Linearity | Relationship between features and target is linear |
| Independence | Observations are independent of each other |
| Homoscedasticity | Constant variance of errors |
| Normality | Errors are normally distributed (for inference) |
</Tab>

<Tab title="Gradient Descent">
### Algorithm
```
repeat until convergence {
  θ_j := θ_j - α (∂/∂θ_j) J(θ)   for all j
}
```

### Variants
- **Batch GD**: Uses all $m$ examples per step — stable but slow for large $m$
- **Stochastic GD**: One example per step — noisy, fast, can escape local minima
- **Mini-batch GD**: Best of both worlds (typical batch size: 32–512)

### Learning Rate $\alpha$
- Too small → slow convergence
- Too large → overshoot, divergence
- **Practical tip**: Try $\alpha \in \{0.001, 0.01, 0.1, 1\}$ on log scale
</Tab>

<Tab title="Regularization">
### Ridge (L2)
$$J(\theta) = \text{MSE} + \lambda \sum_{j=1}^n \theta_j^2$$
- Shrinks coefficients toward zero, never exactly zero
- Better when many features have small effects

### Lasso (L1)
$$J(\theta) = \text{MSE} + \lambda \sum_{j=1}^n |\theta_j|$$
- Can drive coefficients to exactly zero → **feature selection**
- Better when only a few features matter

### Elastic Net
$$J(\theta) = \text{MSE} + \lambda_1 \|\theta\|_1 + \lambda_2 \|\theta\|_2^2$$
- Combines both; useful when features are correlated
</Tab>

<Tab title="Model Evaluation">
### Metrics
| Task | Metrics |
|---|---|
| Regression | MSE, RMSE, MAE, $R^2$, Adjusted $R^2$ |
| Classification | Accuracy, Precision, Recall, F1, ROC-AUC |

### Validation Strategies
- **Train/Validation/Test split** (e.g., 70/15/15)
- **k-Fold Cross-Validation** ($k=5$ or $10$)
- **Leave-One-Out CV** (LOOCV) — low bias, high variance

### Bias-Variance Tradeoff
- **High bias** (underfitting): Model too simple → add features, decrease $\lambda$
- **High variance** (overfitting): Model too complex → more data, increase $\lambda$, feature selection
</Tab>
