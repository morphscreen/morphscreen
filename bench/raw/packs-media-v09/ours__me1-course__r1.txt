<Card title="Lesson Notes">
  ## Key Concepts

  **useState Hook**
  - Returns current state value and a setter function
  - Triggers re-render when state changes
  - Can hold any type: primitives, objects, arrays

  ```jsx
  const [count, setCount] = useState(0);
  const [user, setUser] = useState({ name: '', email: '' });
  ```

  **useReducer Hook**
  - Better for complex state logic
  - Takes reducer function and initial state
  - Returns state and dispatch function

  ```jsx
  const [state, dispatch] = useReducer(reducer, initialState);
  ```

  **Best Practices**
  - Keep state minimal and derived values computed
  - Use functional updates when new state depends on previous
  - Group related state into objects when they change together

  <Details title="Common Pitfalls" open="false">
    - Mutating state directly instead of creating new objects
    - Forgetting that setState is asynchronous
    - Storing derived data that could be computed during render
  </Details>
</Card>
