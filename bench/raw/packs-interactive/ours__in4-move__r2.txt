<Card title="4 weeks before" subtitle="Week -4">
<Checklist name="week-4">
- [x] Notify landlord/agent of move-out date
- [x] Book removal company or van hire
- [ ] Start decluttering — donate, sell, recycle
- [ ] Request time off work for moving days
- [ ] Arrange mail redirection with Royal Mail
- [ ] Notify utility suppliers (electric, gas, water, broadband)
- [ ] Update address with bank, GP, DVLA, employer
</Checklist>
</Card>

<Card title="3 weeks before" subtitle="Week -3">
<Checklist name="week-3">
- [x] Order packing boxes, tape, bubble wrap, labels
- [ ] Pack non-essentials: books, décor, out-of-season clothes
- [ ] Take meter readings (photos for records)
- [ ] Arrange final broadband/TV install at new address
- [ ] Confirm parking permits for both addresses
- [ ] Defrost freezer if moving it
</Checklist>
</Card>

<Card title="2 weeks before" subtitle="Week -2">
<Checklist name="week-2">
- [ ] Pack kitchen non-essentials, leave basics out
- [ ] Arrange childcare/pet care for moving day
- [ ] Confirm removal company details (times, access, insurance)
- [ ] Label boxes by room + contents (colour code)
- [ ] Pack "first night" box: kettle, bedding, toiletries, chargers
- [ ] Return any borrowed items (library, neighbours)
</Checklist>
</Card>

<Card title="1 week before" subtitle="Week -1">
<Checklist name="week-1">
- [ ] Pack remaining clothes, toiletries, daily items
- [ ] Drain washing machine / disconnect appliances
- [ ] Clean as you empty each room
- [ ] Final meter readings on moving morning
- [ ] Leave keys, manuals, spare keys for landlord/new owners
- [ ] Redirect post — confirm start date
</Checklist>
</Card>

<Card title="Moving week" subtitle="Move-in / Move-out days">
<Checklist name="moving-week">
- [ ] Supervise movers / load van systematically
- [ ] Final walkthrough — photos of empty flat
- [ ] Hand over keys / sign checkout inventory
- [ ] Unload at new address — direct boxes to correct rooms
- [ ] Check inventory against boxes delivered
- [ ] Set up beds, kettle, Wi-Fi first
</Checklist>
</Card>

<Card title="First week in new home" subtitle="Week +1">
<Checklist name="week-plus-1">
- [ ] Unpack essentials: kitchen, bathroom, bedroom
- [ ] Register with new GP / dentist
- [ ] Update car insurance, electoral roll, subscriptions
- [ ] Test smoke/CO alarms, locate stopcock, fuse box
- [ ] Introduce yourself to neighbours
- [ ] Celebrate! 🎉
</Checklist>
</Card>
