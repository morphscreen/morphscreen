# Moving House Checklist

<Card title="Overall Progress" subtitle="6 weeks until move day">
<Progress value="23" max="68" label="Tasks completed" tone="info" />
</Card>

<Card title="Week -6 (6 weeks before)" subtitle="Planning & research">
<Checklist name="week-6">
- [x] Create moving budget spreadsheet
- [x] Research and compare 3 moving companies
- [x] Book moving company for move date
- [ ] Notify landlord/estate agent of move-out date
- [ ] Request time off work for moving week
- [ ] Start decluttering - donate/sell unwanted items
- [ ] Measure furniture for new flat layout
</Checklist>
</Card>

<Card title="Week -5 (5 weeks before)" subtitle="Admin & utilities">
<Checklist name="week-5">
- [x] Set up mail redirection with Royal Mail
- [x] Notify bank, employer, GP, dentist of address change
- [ ] Compare and switch energy suppliers for new address
- [ ] Arrange broadband installation at new flat
- [ ] Update car insurance and DVLA address
- [ ] Cancel/transfer gym membership
- [ ] Notify subscriptions (Amazon, Netflix, etc.)
</Checklist>
</Card>

<Card title="Week -4 (4 weeks before)" subtitle="Packing prep">
<Checklist name="week-4">
- [x] Order packing boxes, tape, bubble wrap, markers
- [x] Label boxes by room (Kitchen, Bedroom, Bathroom, etc.)
- [ ] Pack non-essentials: books, decor, off-season clothes
- [ ] Pack guest room / spare room completely
- [ ] Create "first night" box (toiletries, chargers, snacks, bedding)
- [ ] Photograph electronics connections before unplugging
- [ ] Start using up freezer/pantry food
</Checklist>
</Card>

<Card title="Week -3 (3 weeks before)" subtitle="Deep packing">
<Checklist name="week-3">
- [ ] Pack kitchen non-essentials (appliances, bakeware, extra crockery)
- [ ] Pack bedroom non-essentials (extra linens, out-of-season clothes)
- [ ] Pack bathroom non-essentials (extra towels, toiletries)
- [ ] Dismantle flat-pack furniture not needed daily
- [ ] Arrange childcare/pet care for moving day
- [ ] Confirm parking permits for moving van at both addresses
- [ ] Defrost freezer (if taking it)
</Checklist>
</Card>

<Card title="Week -2 (2 weeks before)" subtitle="Final preparations">
<Checklist name="week-2">
- [ ] Pack remaining kitchen items (keep 2 plates, 2 mugs, basics)
- [ ] Pack remaining bedroom/bathroom items
- [ ] Pack valuables & important documents separately (carry yourself)
- [ ] Confirm moving company arrival time
- [ ] Take final meter readings at current flat
- [ ] Clean oven, fridge, windows
- [ ] Return any borrowed items (library books, neighbor's tools)
</Checklist>
</Card>

<Card title="Week -1 (Moving week)" subtitle="Final days">
<Checklist name="week-1">
- [ ] Pack "essentials" suitcase for each person (3 days clothes, meds, docs)
- [ ] Pack cleaning supplies for final clean (keep accessible)
- [ ] Disconnect and drain washing machine
- [ ] Do final deep clean of current flat
- [ ] Take dated photos of empty flat for deposit evidence
- [ ] Leave keys, manuals, warranties for new tenants
- [ ] Redirect final post check
</Checklist>
</Card>

<Card title="Moving Day" subtitle="The big day">
<Checklist name="moving-day">
- [ ] Do final walkthrough with landlord/agent
- [ ] Hand over keys, get receipt
- [ ] Supervise movers - check inventory list
- [ ] Take meter readings at new flat on arrival
- [ ] Direct boxes to correct rooms at new flat
- [ ] Assemble beds first (so you can sleep!)
- [ ] Unpack "first night" box
- [ ] Order takeaway, relax
</Checklist>
</Card>

<Card title="Week +1 (After move)" subtitle="Settling in">
<Checklist name="week-plus-1">
- [ ] Unpack kitchen essentials, set up appliances
- [ ] Unpack bathroom, hang shower curtain
- [ ] Register with new GP/dentist
- [ ] Update electoral roll
- [ ] Explore neighborhood - find supermarket, pharmacy, park
- [ ] Meet neighbors
- [ ] Celebrate! 🎉
</Checklist>
</Card>
