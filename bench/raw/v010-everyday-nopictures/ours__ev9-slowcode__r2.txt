# Speeding Up Your 2 GB CSV Processing

Reading a 2 GB CSV in Python can be painfully slow if you're using the wrong approach. Let's diagnose the bottleneck and fix it.

## The 3 biggest wins (in order)

<Columns>
<Card title="1. Use the right tool">
**Pandas** with the `engine="c"` parser is 10-50x faster than pure Python for most CSV work. For 2 GB, it handles chunking automatically.

<Badge tone="success">Best for: most cases</Badge>
</Card>

<Card title="2. Read in chunks">
Never load 2 GB into memory at once. Process in 100k-row chunks to keep memory flat.

<Badge tone="info">Best for: large files</Badge>
</Card>

<Card title="3. Use Polars">
**Polars** is a Rust-based DataFrame library that's 5-10x faster than Pandas for CSV reading, especially on multi-core machines.

<Badge tone="warning">Best for: speed-critical</Badge>
</Card>
</Columns>

## Option A: Pandas (easiest upgrade)

<Card title="Pandas with chunking">
```python
import pandas as pd

# Read in chunks of 100k rows
chunks = pd.read_csv('large.csv', chunksize=100_000, engine='c')

results = []
for chunk in chunks:
    # Process each chunk
    filtered = chunk[chunk['column'] > 100]
    results.append(filtered)

# Combine if needed
final = pd.concat(results)
```
</Card>

<Callout tone="info" title="Why this helps">
- The `c` engine is compiled C code, not interpreted Python
- Chunking keeps memory under control (no 2 GB RAM spike)
- Vectorized operations on columns are 100x faster than row-by-row loops
</Callout>

## Option B: Polars (fastest)

<Card title="Polars — the speed king">
```python
import polars as pl

# Lazy API — only computes what you need
df = pl.scan_csv('large.csv')

# Filter, aggregate, then collect
result = (
    df.filter(pl.col('column') > 100)
      .group_by('category')
      .agg(pl.col('value').mean())
      .collect()
)
```
</Card>

<Stat label="Speedup vs plain Python" value="10-50x" tone="success" icon="chart-line" />

## Option C: If you must stay with pure Python

<Card title="Optimized built-in approach">
```python
import csv

with open('large.csv', 'r') as f:
    reader = csv.DictReader(f)  # Use DictReader for named access
    for row in reader:
        # Process row — but avoid building lists of everything!
        if float(row['amount']) > 100:
            process(row)
```
</Card>

<Callout tone="warning" title="Key mistakes to avoid">
- ❌ Don't use `readlines()` — loads everything into memory
- ❌ Don't append to a list for every row — use aggregations
- ❌ Don't parse with `split(',')` — misses quoted fields
- ❌ Don't use `csv.reader` when you need column names — use `DictReader`
</Callout>

## Advanced: Parallel processing

<Card title="Multi-core processing with Polars">
```python
import polars as pl

# Polars automatically uses all cores
df = pl.read_csv('large.csv')

# Or use the streaming engine for even bigger files
df = pl.read_csv('large.csv', 
                 low_memory=True,  # process in streaming mode
                 use_polars_parallel=True)
```

## Quick start — copy-paste this

<Card title="Template for fast CSV processing">
```python
# Option 1: Pandas (most compatible)
import pandas as pd

def process_large_csv(filename):
    chunks = pd.read_csv(filename, chunksize=100_000, engine='c')
    total = 0
    for chunk in chunks:
        # Your processing here
        total += chunk['amount'].sum()
    return total

# Option 2: Polars (fastest)
import polars as pl

def process_large_csv_fast(filename):
    return (
        pl.scan_csv(filename)
          .select(pl.sum('amount'))
          .collect()
          .item()
    )
```
