# Speeding Up Large CSV Processing in Python

Reading a 2 GB CSV in Python can be painfully slow if you're using the wrong approach. Here's a practical guide to dramatically speed things up, from quick wins to advanced techniques.

<Callout tone="warning" title="Know your bottleneck first">
Before optimizing, measure whether the slowness is from I/O, parsing, or memory. Use `time` around each phase of your script to pinpoint where time goes.
</Callout>

## 1. Quick Wins (Minimal Code Changes)

<Card title="Start with these">
<Steps>
<Step title="Use a faster CSV reader" status="done" subtitle="Pandas with C engine">
Replace the built-in `csv` module with `pandas.read_csv()` — it uses a C parser that's 5-10x faster.
</Step>
<Step title="Specify dtypes" status="done" subtitle="Avoid type inference overhead">
Tell pandas what each column is to skip its inference step.
</Step>
<Step title="Read in chunks" status="done" subtitle="Don't load everything at once">
Process the file in manageable pieces to reduce memory pressure and speed up each iteration.
</Step>
</Steps>
</Card>

<Card title="Before vs. After">
<Tabs>
<Tab title="Slow version">
<Code file="slow.py">
import csv

    reader = csv.reader(f)
    data = []
    for row in reader:
        data.append(row)
    # process data...
</Code>
</Tab>
<Tab title="Fast version">
<Code file="fast.py">
import pandas as pd

# Read only needed columns, with known dtypes
dtypes = {'col1': 'int32', 'col2': 'float32', 'col3': 'category'}
chunksize = 100_000

for chunk in pd.read_csv('huge.csv', dtype=dtypes, 
                         usecols=['col1', 'col2', 'col3'],
                         chunksize=chunksize):
    # process each chunk
    process(chunk)
</Code>
</Tab>

## 2. Memory-Efficient Techniques

<Card title="For when the file is too big for RAM">
<Columns>
<Card title="Chunked processing">
Process the file in slices, aggregating results as you go. This keeps memory flat regardless of file size.

```python
import pandas as pd

total = 0
for chunk in pd.read_csv('huge.csv', chunksize=50_000):
    total += chunk['amount'].sum()
print(f"Total: {total}")
```

<Card title="Use Dask for out-of-core">
Dask DataFrames mirror pandas but work on data larger than RAM by dividing work across chunks.

```python
import dask.dataframe as dd

df = dd.read_csv('huge.csv', blocksize='100MB')
result = df.groupby('category').sum().compute()
```

## 3. Advanced Optimizations

<Card title="Go beyond pandas">
<Columns>
<Card title="Use PyArrow">
Apache Arrow's CSV reader is often 2-3x faster than pandas' C engine for large files.

```python
import pyarrow.csv as pv

table = pv.read_csv('huge.csv', 
                    convert_options=pv.ConvertOptions(column_types={'id': 'int64'}))
df = table.to_pandas()
```

<Callout tone="info" title="Pro tip: If you can change the file format">
If the CSV is generated by you, consider switching to a columnar format like **Parquet** or **Feather**. These can be read 10-50x faster and take less disk space. If you must keep CSV, at least compress it (`.csv.gz`) — pandas can read compressed files directly and often faster due to reduced I/O.
</Callout>
