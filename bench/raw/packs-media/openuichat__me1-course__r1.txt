They were introduced in React 16.8.\n\n### Key Rules\n1. **Only call hooks at the top level** — not inside loops, conditions, or nested functions\n2. **Only call hooks from React functions** — components or custom hooks\n3. **Hook names must start with `use`** — e.g., `useState`, `useEffect`, `useCustomHook`\n\n### Common Built-in Hooks\n| Hook | Purpose |\n|------|---------|\n| `useState` | Add state to function components |\n| `useEffect` | Handle side effects (data fetching, subscriptions, DOM manipulation) |\n| `useContext` | Access React context without nesting |\n| `useRef` | Persist mutable values across renders |\n| `useMemo` / `useCallback` | Optimize performance by memoizing values/functions |\n\n### Code Example: `useState`\n```jsx\nimport { useState } from 'react';\n\nfunction Counter() {\n  const [count, setCount] = useState(0);\n  return (\n    <button onClick={() => setCount(count + 1)}>\n      Count: {count}\n    </button>\n  );\n}\n```\n\n### Code Example: `useEffect`\n```jsx\nimport { useState, useEffect } from 'react';\n\nfunction UserProfile({ userId }) {\n  const [user, setUser] = useState(null);\n  \n  useEffect(() => {\n    fetch(`/api/users/${userId}`)\n      .then(res => res.json())\n      .then(data => setUser(data));\n  }, [userId]); // dependency array\n  \n  return user ? <div>{user.name}</div> : <div>Loading...</div>;\n}\n```\n\n### Key Takeaways\n- Hooks let you use state and other React features without writing a class\n- The dependency array in `useEffect` controls when the effect runs\n- Custom hooks let you extract component logic into reusable functions\n- Always follow the Rules of Hooks to avoid bugs", "card")
