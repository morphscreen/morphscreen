### Key Concepts

**State vs Props**
- **Props**: Data passed from parent to child (read-only)
- **State**: Internal data managed by the component (mutable)

**useState Hook**
```jsx
const [count, setCount] = useState(0);
```
- Returns current state value and a setter function
- Setter triggers re-render with new value

**Lifting State Up**
- Move shared state to closest common ancestor
- Pass data down via props
- Pass setter functions down for updates

**Immutability**
- Never mutate state directly: `state.items.push()` ❌
- Always create new objects/arrays: `setItems([...items, newItem])` ✅

### Common Patterns

| Pattern | Use Case |
|---------|----------|
| Functional updates | `setCount(c => c + 1)` when updates depend on previous state |
| Lazy initialization | `useState(() => expensiveCalculation())` for expensive initial values |
| Multiple state variables | Separate unrelated state for cleaner updates |
