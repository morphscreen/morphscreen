Compound Components\nShare implicit state between components without props drilling.\n\n```jsx\n<Tabs>\n  <Tabs.List>\n    <Tabs.Trigger value=\"account\">Account</Tabs.Trigger>\n    <Tabs.Trigger value=\"settings\">Settings</Tabs.Trigger>\n  </Tabs.List>\n  <Tabs.Content value=\"account\">...</Tabs.Content>\n  <Tabs.Content value=\"settings\">...</Tabs.Content>\n</Tabs>\n```\n\n### 2. Render Props / Children as Function\nInvert control to the consumer for maximum flexibility.\n\n```jsx\n<DataProvider render={data => <Dashboard data={data} />} />\n```\n\n### 3. Custom Hooks for Logic Reuse\nExtract stateful logic into reusable hooks.\n\n```jsx\nfunction useLocalStorage(key, initialValue) {\n  const [value, setValue] = useState(() => {\n    const stored = localStorage.getItem(key);\n    return stored ? JSON.parse(stored) : initialValue;\n  });\n  useEffect(() => localStorage.setItem(key, JSON.stringify(value)), [key, value]);\n  return [value, setValue];\n}\n```\n\n### 4. Higher-Order Components (HOCs)\nWrap components to inject props or behavior.\n\n```jsx\nconst withAuth = (Component) => (props) => {\n  const { user } = useAuth();\n  return user ? <Component {...props} /> : <LoginPrompt />;\n};\n```\n\n### Key Takeaways\n- **Compound components** reduce prop drilling for related UI\n- **Render props** give consumers control over rendering\n- **Custom hooks** are the modern standard for logic reuse\n- **HOCs** still useful for cross-cutting concerns (auth, logging)\n\n> **Pro Tip**: Prefer custom hooks over HOCs for new code — they compose better and avoid wrapper hell.", "card")
