# Speeding up large CSV processing in Python

Reading a 2 GB CSV in Python can be slow for several reasons. Let's diagnose and fix the most common bottlenecks.

<Card title="Quick wins: 3 things to try first">
<Steps>
<Step title="Use a faster parser" status="current" subtitle="Pandas with engine='pyarrow' or 'c'">
Replace the default Python parser with a C-based one. If you're using pandas, this alone can give **5-10x speedup**.
</Step>
<Step title="Read only what you need" status="todo" subtitle="Columns + rows">
Don't load the whole file. Specify columns with `usecols` and filter rows early.
</Step>
<Step title="Use chunking" status="todo" subtitle="Process in batches">
For 2 GB, process the file in chunks of 50k-100k rows instead of loading it all at once.
</Step>
</Steps>
</Card>

<Card title="Which approach fits your situation?">
<Tabs>
<Tab title="Using pandas">
<Callout tone="info" title="Best for: data analysis, filtering, grouping">
</Callout>

```python
# 🐌 Slow: default Python parser
df = pd.read_csv('large_file.csv')

# 🚀 Fast: C engine with specific dtypes
df = pd.read_csv(
    'large_file.csv',
    engine='c',           # C parser, much faster than Python
    low_memory=False,     # Avoid mixed-type inference per chunk
    dtype={'col1': 'int32', 'col2': 'category'},  # Smaller dtypes
    usecols=['col1', 'col2', 'col3'],  # Only needed columns
    nrows=1000000         # Optional: limit rows for testing
)

# 🚀 Fastest: PyArrow backend (pandas 2.0+)
df = pd.read_csv(
    'large_file.csv',
    engine='pyarrow',     # Arrow-based, parallelized
    dtype_backend='pyarrow'
)
```

<Stat label="Speed comparison" value="10-50x" change="faster" tone="success" />
</Tab>

<Tab title="Using Polars">
<Callout tone="info" title="Best for: maximum speed, memory efficiency">
</Callout>

```python
import polars as pl

# 🚀 Polars is lazy and parallel by default
df = pl.scan_csv('large_file.csv')  # Lazy: doesn't load yet
result = (
    df
    .filter(pl.col('date') > '2024-01-01')
    .select(['col1', 'col2'])
    .collect(streaming=True)  # Process in streaming fashion
)
```

<Stat label="Speed vs pandas" value="5-20x" change="faster" tone="success" />
</Tab>

<Tab title="Manual chunking">
<Callout tone="info" title="Best for: custom processing, limited memory">
</Callout>

```python
import csv
from itertools import islice

def process_chunk(chunk):
    # Your processing logic here
    return chunk

chunk_size = 100000
with open('large_file.csv', 'r') as f:
    reader = csv.DictReader(f)
    while True:
        chunk = list(islice(reader, chunk_size))
        if not chunk:
            break
        result = process_chunk(chunk)
        # Save or aggregate result
```

<KeyValue title="Common bottlenecks and fixes">
| Symptom | Likely cause | Fix |
|---|---|---|
| High CPU, slow parse | Python parser | Use `engine='c'` or `engine='pyarrow'` |
| High memory, then slow | Loading all data | Use `chunksize` or streaming |
| Slow after loading | Inefficient dtypes | Specify `dtype` as smaller types |
| Disk I/O at 100% | Single-threaded read | Try `polars` or `dask` for parallel I/O |
</KeyValue>
</Card>

<Card title="Memory-efficient dtypes cheat sheet">
Saving memory = fewer disk reads = faster processing.

| Data type | Default pandas | Optimized | Memory savings |
|---|---|---|---|
| Integer | `int64` | `int32` or `int16` | 50-75% |
| Float | `float64` | `float32` | 50% |
| String with repeats | `object` | `category` | 80-90% |
| Date | `object` | `datetime64` | 60% |

```python
# Example: specify dtypes when reading
dtype_spec = {
    'user_id': 'int32',
    'age': 'int8',
    'salary': 'float32',
    'department': 'category',
    'signup_date': 'datetime64[ms]'
}
df = pd.read_csv('large.csv', dtype=dtype_spec, engine='c')
```
