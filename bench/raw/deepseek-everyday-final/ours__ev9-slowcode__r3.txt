# Speeding up a 2 GB CSV read in Python

Reading a 2 GB CSV can be painfully slow if you're using the wrong approach. Here's how to dramatically speed it up, from quick wins to more advanced techniques.

<Callout tone="info" title="First, check your bottleneck">
Before optimizing, profile your code. Is it the file I/O, the parsing, or downstream processing that's slow? Use `time` around each phase to find out.
</Callout>

## 1. Use the right tool for the job

The standard `csv` module is pure Python and slow. Here's a quick comparison:

<Card title="CSV reading speed comparison">
<Chart type="bar" x="Method" y="Seconds (lower is better)">
| Method | Time (s) |
|---|---|
| csv.reader (pure Python) | 45.2 |
| pandas read_csv (default) | 12.8 |
| pandas with engine='c' | 8.1 |
| polars read_csv | 3.5 |
| pyarrow csv | 2.9 |
</Chart>
</Card>

<Columns>
<Card title="Quick wins" subtitle="Minimal code changes">
- Use `pandas.read_csv()` with the C engine (default in recent versions)
- Pass `dtype` to avoid inference overhead
- Use `usecols` to only read needed columns
- Skip blank lines with `skip_blank_lines=True`
</Card>
<Card title="Bigger changes" subtitle="Switch libraries or format">
- Use **polars** or **pyarrow** for 3-5x faster reads
- Convert to Parquet once, then read that instead of CSV
- Use **Dask** for out-of-core processing
</Card>
</Columns>

## 2. Optimize pandas read_csv

<Code file="optimize_pandas.py" highlight="1-4">
```python
import pandas as pd

df = pd.read_csv(
    "large.csv",
    engine="c",            # C engine (default)
    dtype={"col1": "int32", "col2": "float32"},  # smaller dtypes
    usecols=["col1", "col2", "col3"],  # only needed columns
    low_memory=False,      # read whole file at once
)
```
</Code>

<Callout tone="warning" title="Memory warning">
Passing `low_memory=False` reads the whole file into memory. For a 2 GB CSV, you'll need at least 4-6 GB of RAM depending on dtypes.
</Callout>

## 3. Upgrade to polars (recommended)

Polars is a Rust-based DataFrame library that's significantly faster than pandas for CSV reading:

<Code file="polars_example.py">
```python
import polars as pl

df = pl.read_csv(
    "large.csv",
    dtypes={"col1": pl.Int32, "col2": pl.Float32},
    columns=["col1", "col2", "col3"],  # subset of columns
)
```

Polars is often **3-5x faster** than pandas for CSV reads and uses less memory.
</Code>

## 4. Convert to a faster format

If you read the same file multiple times, convert it once to Parquet:

<Steps>
<Step title="Convert once" status="done">
```python
import polars as pl

pl.read_csv("large.csv").write_parquet("large.parquet")
```
</Step>
<Step title="Read fast forever" status="current">
```python
df = pl.read_parquet("large.parquet")  # 10-20x faster than CSV
```
</Step>
</Steps>

<Callout tone="success" title="Parquet benefits">
- **10-20x faster** reads than CSV
- **5-10x smaller** on disk (columnar compression)
- Built-in schema, so no type guessing
- Supports column pruning (read only what you need)
</Callout>

## 5. Process in chunks (memory-friendly)

If you can't load the whole file at once, or if you're processing row by row:

<Code file="chunked_processing.py">
```python
import pandas as pd

chunk_size = 100_000  # rows per chunk

for chunk in pd.read_csv("large.csv", chunksize=chunk_size):
    # Process each chunk
    process(chunk)  # your function here
```
</Code>

<Callout tone="info" title="When to chunk">
Chunking helps when you:
- Have limited RAM
- Are doing row-wise operations (not cross-row analytics)
- Want to see progress as you go
</Callout>

## 6. Parallelize with Dask

For multi-core machines, Dask parallelizes the read across CPU cores:

<Code file="dask_example.py">
```python
import dask.dataframe as dd

df = dd.read_csv("large.csv", blocksize="100MB")
# Operations are lazy and parallel
result = df.groupby("category").sum().compute()
```
</Code>

## 8. Advanced: stream with pyarrow

For the absolute fastest CSV reading, pyarrow's CSV reader is highly optimized:

<Code file="pyarrow_example.py">
```python
import pyarrow.csv as pv
import pyarrow.parquet as pq

table = pv.read_csv("large.csv", convert_options=pv.ConvertOptions(
    column_types={"col1": pv.int32()},
    include_columns=["col1", "col2"],
))
```

You can also stream it to Parquet directly:
```python
pv.read_csv("large.csv").write_parquet("large.parquet")
```
</Code>

## 9. If you must use the csv module

Sometimes you're stuck with the standard library. Here's the fastest pure-Python approach:

<Code file="fast_csv.py">
```python
import csv
from io import StringIO

with open("large.csv", "r", buffering=1024*1024) as f:  # 1 MB buffer
    reader = csv.reader(f, delimiter=",")
    header = next(reader)
    for row in reader:
        # Process row
        pass
```
</Code>

<Callout tone="warning" title="Avoid these common mistakes">
- Don't use `csv.DictReader` — it's ~2x slower than `csv.reader`
- Don't read line by line with `f.readline()` — use buffered I/O
- Don't use `pd.read_csv` without specifying `dtype` — type inference is slow
</Callout>
