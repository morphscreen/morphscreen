# Speeding Up Large CSV Processing in Python

Reading a 2 GB CSV file in Python can be painfully slow if you're using the wrong approach. Here's how to dramatically speed things up.

<Callout tone="info" title="Key insight">
The biggest bottleneck is usually reading the file line-by-line with pure Python. Switching to a chunked, vectorized approach can give you **10-50x speedups**.
</Callout>

## First: Profile Your Current Setup

Before optimizing, check where your time actually goes:

<Card title="Common bottlenecks">
| Bottleneck | Impact |
|---|---|
| Reading line-by-line with `for row in file` | High |
| Using `csv.DictReader` (creates dict per row) | High |
| Converting types one-by-one in Python loops | Medium |
| Appending to lists and then converting to arrays | Medium |
| Using `pandas.read_csv` without optimizations | Low |
| Memory swapping due to holding everything in RAM | Critical |
</Card>

<Step title="If you must use Pandas" status="todo" subtitle="Use these parameters">
```python
import pandas as pd

df = pd.read_csv(
    "huge.csv",
    engine="c",              # C parser (default, but explicit)
    low_memory=False,        # Read all in one go, not column-by-column
    dtype={"col1": "int32"}, # Specify types to avoid guessing
    usecols=["col1", "col2"],# Only needed columns
    nrows=1_000_000          # Test with a subset first
)
```
</Step>

<Step title="Process in chunks" status="todo" subtitle="For memory efficiency">
```python
import pandas as pd

chunk_size = 100_000
results = []

for chunk in pd.read_csv("huge.csv", chunksize=chunk_size):
    # Process each chunk
    results.append(chunk.groupby("category").sum())

final = pd.concat(results).groupby(level=0).sum()
```
</Step>

<Step title="Parallelize across cores" status="todo" subtitle="Use all your CPU">
```python
import polars as pl

# Polars does this automatically
df = pl.read_csv("huge.csv")

# For Pandas, use multiprocessing with chunks
from multiprocessing import Pool

def process_chunk(chunk):
    return chunk.groupby("category").sum()

with Pool() as pool:
    results = pool.map(process_chunk, pd.read_csv("huge.csv", chunksize=100_000))
```
</Step>
</Steps>

## Advanced: When You Only Need Part of the Data

<Callout tone="warning" title="Don't read what you don't need">
If you only need a subset, you can avoid reading the whole file:

- **Only certain columns**: `usecols` in Pandas, `columns` in Polars
- **Only certain rows**: Use `skiprows` and `nrows` to sample
- **Filter while reading**: Use Polars' lazy API with `scan_csv()`
</Callout>

<Details title="Polars lazy filtering example">
```python
import polars as pl

# Only reads matching rows from disk
df = (
    pl.scan_csv("huge.csv")
    .filter(pl.col("age") > 30)
    .select(["name", "email"])
    .collect()
)
```
This can be **10x faster** than reading everything and then filtering.
</Details>
