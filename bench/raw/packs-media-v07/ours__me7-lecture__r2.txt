<Card title="Slides: Main Points">
<Tabs>
<Tab title="Supervised Learning">
- **Definition**: Learning a function that maps input to output based on example input-output pairs
- **Key algorithms**: Linear Regression, Logistic Regression, Decision Trees, Random Forests, SVMs, Neural Networks
- **Loss functions**: MSE (regression), Cross-entropy (classification)
- **Overfitting prevention**: Regularization (L1/L2), Cross-validation, Early stopping
</Tab>
<Tab title="Unsupervised Learning">
- **Definition**: Finding patterns in data without labeled outputs
- **Clustering**: K-means, Hierarchical, DBSCAN
- **Dimensionality reduction**: PCA, t-SNE, UMAP
- **Anomaly detection**: Isolation Forest, Local Outlier Factor
</Tab>
<Tab title="Model Evaluation">
- **Metrics**: Accuracy, Precision, Recall, F1-score, AUC-ROC
- **Validation strategies**: Train/validation/test split, k-fold cross-validation
- **Bias-Variance Tradeoff**: Underfitting (high bias) vs Overfitting (high variance)
- **Learning curves**: Diagnosing bias vs variance problems
</Tab>
<Tab title="Practical Considerations">
- **Data preprocessing**: Scaling, encoding categorical variables, handling missing data
- **Feature engineering**: Creating informative features from raw data
- **Hyperparameter tuning**: Grid search, Random search, Bayesian optimization
- **Deployment concerns**: Model monitoring, data drift, retraining pipelines
</Tab>
</Tabs>
</Card>
