## Slides: Main Points

<Card title="Slides: Key Takeaways" subtitle="12 slides covering foundational concepts">
<Tabs>
<Tab title="Definitions">
**What is Machine Learning?**
- Algorithms that improve automatically through experience
- Learning from data without explicit programming
- Core idea: pattern recognition + generalization

**Types of Learning**
- Supervised: labeled data → prediction
- Unsupervised: unlabeled data → structure discovery
- Reinforcement: actions → rewards → policy
</Tab>
<Tab title="Core Concepts">
**Bias-Variance Tradeoff**
- High bias → underfitting (too simple)
- High variance → overfitting (too complex)
- Goal: find the sweet spot

**Model Evaluation**
- Train/validation/test splits
- Cross-validation for robust estimates
- Metrics: accuracy, precision, recall, F1, AUC-ROC
</Tab>
<Tab title="Workflow">
**End-to-End ML Pipeline**
1. Problem definition & success metrics
2. Data collection & cleaning
3. Exploratory data analysis (EDA)
4. Feature engineering
5. Model selection & training
6. Hyperparameter tuning
7. Evaluation & error analysis
8. Deployment & monitoring
</Tab>
<Tab title="Common Pitfalls">
- Data leakage (using test info in training)
- Ignoring class imbalance
- Overfitting to validation set
- Not establishing baselines
- Deploying without monitoring
</Tab>
</Tabs>
</Card>
